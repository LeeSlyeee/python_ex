# 260123 랭체인\_챗GPT_RAG.py 핵심 요약

이 문서는 `260123 랭체인_챗GPT_RAG.py` 실습을 통해 학습한 **RAG(Search-Augmented Generation)** 의 전체 파이프라인(문서 로드, 분할, 임베딩, 저장, 검색, 답변 생성)에 대한 요점 정리입니다.

---

## 1. RAG(Retrieval-Augmented Generation)란?

LLM(거대언어모델)이 **외부 데이터(문서 등)** 를 검색(Retrieval)하여 그 정보를 바탕으로 답변을 생성(Generation)하는 기술입니다. LLM이 학습하지 않은 최신 정보나 비공개 문서를 참조하여 답변할 수 있게 해줍니다.

---

## 2. RAG 구현 단계별 핵심 내용

### 2.1 문서 로드 (Document Loading)

- **클래스**: `TextLoader`
- **역할**: 로컬에 저장된 텍스트 파일(`AI.txt`)을 읽어와서 LangChain이 처리할 수 있는 `Document` 객체로 변환합니다.
- **코드**:
  ```python
  documents = TextLoader(file_path).load()
  ```

### 2.2 텍스트 분할 (Text Splitting)

- **클래스**: `RecursiveCharacterTextSplitter`
- **역할**: LLM의 토큰 제한을 넘지 않도록 긴 문서를 작은 조각(Chunk)으로 나눕니다.
- **주요 파라미터**:
  - `chunk_size`: 청크 하나당 최대 글자 수.
  - `chunk_overlap`: 청크 사이의 중복 구간 (문맥 단절 방지).
- **코드**:
  ```python
  text_splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=20)
  docs = text_splitter.split_documents(documents)
  ```

### 2.3 임베딩 생성 (Embedding)

- **클래스**: `OpenAIEmbeddings`
- **역할**: 텍스트를 컴퓨터가 이해할 수 있는 숫자 벡터(Vector)로 변환합니다. 의미상 가까운 단어는 벡터 공간에서 가깝게 위치하게 됩니다.
- **모델**: `text-embedding-ada-002` (OpenAI 표준 임베딩 모델).

### 2.4 벡터 저장소 구축 (Vector Store)

- **클래스**: `Chroma`
- **역할**: 변환된 문서 벡터들을 저장하고, 나중에 질문과 유사한 문서를 빠르게 검색할 수 있는 데이터베이스 역할을 합니다.
- **특징**: `persist_directory="data"` 옵션을 주어 로컬 디스크에 데이터를 영구 저장할 수 있습니다.
- **코드**:
  ```python
  db = Chroma.from_documents(docs, embeddings, persist_directory="data")
  ```

### 2.5 QA 체인 및 LLM (QA Chain)

- **클래스**: `ChatOpenAI`, `load_qa_chain`
- **역할**:
  1. `ChatOpenAI`: 답변을 생성할 LLM을 초기화합니다.
  2. `load_qa_chain`: 검색된 문서(Context)와 질문(Question)을 LLM에 전달하는 파이프라인을 만듭니다.
- **체인 타입 (`chain_type="stuff"`)**:
  - 검색된 관련된 문서들을 **몽땅(Stuff)** 프롬프트에 넣어서 LLM에게 전달하는 가장 단순하고 일반적인 방식입니다.

---

## 3. 실행 프로세스 (Execution Flow)

1. **질문 정의**: 사용자가 질문을 입력합니다. (예: "AI란?")
2. **유사도 검색 (`db.similarity_search`)**:
   - 벡터 저장소(`db`)에서 질문 벡터와 가장 유사도가 높은 문서 청크들을 찾아옵니다.
3. **답변 생성 (`chain.run`)**:
   - 찾아온 문서들(`input_documents`)과 질문(`question`)을 체인에 입력합니다.
   - LLM은 이 문서들의 내용을 바탕으로 최종 답변을 작성합니다.

---

## 4. 참고 사항

- **환경 변수**: 보안을 위해 API Key 등은 `.env` 파일에 저장하고 `dotenv`로 로드하여 사용합니다.
- **절대 경로**: 파일 로드 시 `os.path`를 사용하여 스크립트 실행 위치에 관계없이 파일을 정확히 찾을 수 있도록 절대 경로를 사용하는 것이 안전합니다.
