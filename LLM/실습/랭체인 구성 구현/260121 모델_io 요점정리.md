# 260121 모델\_io.py 핵심 요약

이 문서는 `260121 모델_io.py` 스크립트에서 다루는 LangChain의 핵심 컴포넌트인 **Model I/O (입출력)** 기능과 **모델 비교**, **출력 파싱**에 대한 내용을 정리한 요약본입니다.

## 1. 라이브러리 및 환경 설정

- **LangChain Classic (`langchain_classic`)**: LangChain의 기본 기능을 제공하는 모듈로, 프롬프트 관리, 모델 연동, 출력 파싱 등을 담당합니다.
- **환경 변수 로드 (`dotenv`)**: OpenAI 및 HuggingFace API 키를 안전하게 관리하기 위해 사용합니다.

## 2. 프롬프트 템플릿 (Prompt Template)

LLM에게 보낼 입력 형식을 구체적으로 정의하고 관리하는 도구입니다.

- **`PromptTemplate`**: 동적으로 변하는 입력값(변수)을 템플릿 문자열에 삽입하여 완성된 문장을 만듭니다.
- **주요 파라미터**:
  - `input_variables`: 템플릿 내에서 사용자가 입력할 변수 리스트 (예: `['product']`)
  - `template`: 실제 형식이 정의된 문자열 (예: `"{product}를 홍보해줘"`)

## 3. 언어 모델 (LLMs & Chat Models)

### ChatOpenAI

OpenAI의 챗 모델(GPT 시리즈 등)을 LangChain에서 사용하기 위한 클래스입니다.

- **OpenAI 모델 사용**:
  - `ChatOpenAI(model='gpt-4o-mini', temperature=0)`
  - `invoke()` 메서드를 통해 메시지를 보내고 응답을 받습니다.

### 타사 모델 연동 (HuggingFace 등)

OpenAI 호환 API를 제공하는 다른 플랫폼의 모델도 `ChatOpenAI` 클래스를 통해 쉽게 연동할 수 있습니다.

- **설정 방법**:
  - `base_url`: 해당 서비스의 API 엔드포인트로 변경 (예: HuggingFace Router URL)
  - `api_key`: 해당 서비스의 API 토큰
  - `model`: 사용할 구체적인 모델명 (예: `HuggingFaceTB/SmolLM3-3B`)

## 4. 모델 실험실 (Model Laboratory)

여러 모델의 답변 품질을 동시에 비교하고 테스트하기 위한 유틸리티입니다.

- **`ModelLaboratory`**: 여러 LLM 객체를 리스트로 받아 관리합니다.
- **`compare(prompt)`**: 동일한 질문을 모든 모델에게 던지고, 그 결과를 비교해서 출력해줍니다. 모델 간 성능 차이나 답변 스타일을 확인할 때 매우 유용합니다.

## 5. 출력 파서 (Output Parsers)

LLM이 생성한 비정형 텍스트(문자열)를 Python 리스트나 JSON과 같은 구조화된 데이터로 변환합니다.

- **`CommaSeparatedListOutputParser`**:
  - LLM에게 "콤마(,)로 구분된 목록으로 답해달라"는 지시사항(`format_instructions`)을 자동으로 생성해줍니다.
  - LLM의 응답(예: "사과, 배, 포도")을 받아 Python 리스트(예: `['사과', '배', '포도']`)로 자동 변환(`parse()`)해줍니다.
- **활용 흐름**:
  1. `get_format_instructions()`로 지시사항 획득
  2. 프롬프트에 해당 지시사항 포함 (`partial_variables` 활용)
  3. LLM 응답 수신
  4. `parser.parse(output)`으로 최종 데이터 변환
