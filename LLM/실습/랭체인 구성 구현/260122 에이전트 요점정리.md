# 260122 에이전트.py 핵심 요약

이 문서는 `260122 에이전트.py` 스크립트에서 다루는 LangChain의 **Agents (에이전트)** 기능과 **ReAct (Reasoning + Acting)** 프레임워크에 대한 내용을 정리한 요약본입니다.

---

## 1. 에이전트 (Agents) 핵심 개념

LLM(거대언어모델)을 단순한 텍스트 생성기가 아닌, **"무엇을 해야 할지 판단하고 적절한 도구를 사용하여 문제를 해결하는 추론 엔진"**으로 사용하는 기술입니다.

### ① 역할 (Role)

- 사용자의 질문을 분석하여 **어떤 도구(Tool)**가 필요한지 스스로 결정합니다.
- 도구의 실행 결과를 관찰(Observation)하고, 그것을 바탕으로 최종 답변을 도출합니다.

### ② 도구 (Tools)

에이전트가 세상과 상호작용하기 위해 사용하는 기능들의 집합입니다.

- **`load_tools`**: LangChain에서 미리 만들어둔 도구들을 쉽게 불러오는 함수입니다.
- **주요 도구**:
  - **`wikipedia`**: 위키백과를 검색하여 최신 정보나 사실 관계를 파악합니다. (지식 검색)
  - **`llm-math`**: LLM은 복잡한 계산에 약하므로, 수식을 파이썬 코드로 변환하여 정확하게 계산합니다. (수학 연산)

---

## 2. ReAct 프레임워크 (Reasoning + Acting)

에이전트가 문제를 해결해 나가는 사고 방식을 정의한 개념입니다.

### ① 프로세스 (Process)

1. **Thought (생각)**: "사용자가 에드 시런의 나이를 물어봤어. 먼저 그가 언제 태어났는지 알아야 해."
2. **Action (행동)**: "Wikipedia 검색 도구를 사용하자." (Input: "Ed Sheeran birth year")
3. **Observation (관찰)**: "위키백과에서 1991년생이라는 정보를 찾았어."
4. **Thought (생각)**: "이제 2026년에서 1991년을 빼면 나이를 알 수 있어. 계산 도구를 쓰자."
5. **Action (행동)**: "Calculator 도구 사용." (Input: "2026 - 1991")
6. **Observation (관찰)**: "35라는 결과가 나왔어."
7. **Final Answer (최종 답변)**: "2026년 기준으로 에드 시런은 35세입니다."

### ② 에이전트 유형 (AgentType)

- **`ZERO_SHOT_REACT_DESCRIPTION`**:
  - **Zero Shot**: 예제 데이터를 주지 않아도 스스로 판단함.
  - **React**: 위에서 설명한 추론+행동 방식을 사용함.
  - **Description**: 각 도구가 가진 "설명(Description)" 텍스트만 보고 상황에 맞는 도구를 선택함.

---

## 3. 전체 워크플로우 (Workflow)

1. **설정**: LLM(두뇌)과 Tools(위키백과, 계산기) 준비
2. **초기화**: `initialize_agent`로 두뇌와 도구를 연결하고 행동 지침(AgentType) 부여
3. **실행**: 질문(`agent.run`) -> [생각-행동-관찰] 반복 루프 -> 답변 도출

---

## 4. 실무 팁

- **`verbose=True`**: 이 옵션을 켜두면 에이전트가 내부적으로 어떤 생각과 행동을 하는지 터미널에서 실시간으로 볼 수 있어 디버깅에 필수적입니다.
- **LLM 모델 선정**: 에이전트는 복잡한 추론을 해야 하므로, 보통 성능이 좋은 모델(GPT-4 등)을 사용할 때 도구 선택의 정확도가 높아집니다.
- **도구 조합**: 검색 도구(Search)와 연산 도구(Math/Python)를 함께 주면, "검색 후 계산"이 필요한 복합 질문을 아주 잘 처리합니다.
