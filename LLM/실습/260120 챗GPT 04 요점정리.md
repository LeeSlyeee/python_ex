# 260120 챗GPT 04.py 핵심 요약

이 문서는 `260120 챗GPT 04.py` 스크립트에서 다루는 LangChain의 심화/확장 기능(에이전트, 툴, 정보 추출, 평가 등)을 정리한 요약본입니다. 기본적인 LangChain 사용법에서 나아가, AI가 도구를 사용하여 스스로 문제를 해결하거나 구조화된 데이터를 처리하는 방법을 다룹니다.

## 1. 에이전트 (Agents)

에이전트는 LLM을 "추론 엔진"으로 사용하여, 어떤 행동(Action)을 어떤 순서로 취할지 스스로 결정하는 시스템입니다.

### 1.1 기본 개념

- **LLM**: 상황을 판단하고 결정을 내리는 두뇌 역할을 합니다.
- **Tools**: 에이전트가 사용할 수 있는 도구들의 목록입니다. (예: 터미널 명령어 실행, 구글 검색, 계산기 등)
- **Prompt**: 에이전트에게 역할을 부여하고, 생각하는 방식(ReAct 등)을 지정합니다.
- **AgentExecutor**: 에이전트의 실행 환경(Runtime)으로, 에이전트의 결정에 따라 실제로 툴을 호출하고 결과를 다시 에이전트에게 전달합니다.

### 1.2 ReAct 에이전트 (`create_react_agent`)

- **Reasoning + Acting**의 약자로, [생각 → 행동 → 관찰] 과정을 반복하며 문제를 해결합니다.
- `hub.pull("hwchase17/react")`를 통해 검증된 프롬프트를 가져와 사용합니다.
- 예제에서는 터미널 도구를 사용하여 파일 목록을 확인하는 작업을 수행했습니다.

### 1.3 OpenAI Functions 에이전트 (`create_openai_functions_agent`)

- OpenAI 모델의 **Function Calling** 기능을 활용하는 에이전트입니다.
- ReAct보다 더 안정적이고 구조화된 방식으로 툴을 호출할 수 있습니다.
- `hub.pull("hwchase17/openai-functions-agent")` 프롬프트를 사용합니다.

### 1.4 OpenAI Tools 에이전트 (`create_openai_tools_agent`)

- 최신 OpenAI API의 **Tools** 파라미터를 사용하는 가장 권장되는 방식입니다.
- 여러 툴을 병렬로 호출하거나 더 복잡한 구조를 처리하는 데 유리합니다.
- `hub.pull("hwchase17/openai-tools-agent")` 프롬프트를 사용합니다.

## 2. 도구 (Tools)

에이전트가 외부 세계와 상호작용하기 위한 인터페이스입니다.

### 2.1 내장 도구 (`load_tools`)

- **`terminal`**: 시스템 터미널 명령어를 실행합니다. (`allow_dangerous_tools=True` 필요)
- **`ddg-search`**: DuckDuckGo 검색 엔진을 통해 실시간 웹 정보를 검색합니다.

### 2.2 사용자 정의 도구 (`Tool.from_function`)

- 개발자가 직접 만든 Python 함수를 에이전트가 사용할 수 있는 도구로 변환합니다.
- `func`: 실행할 함수
- `name`: 도구의 이름 (LLM이 선택할 때 사용)
- `description`: 도구에 대한 설명 (LLM이 언제 이 도구를 써야 할지 판단하는 근거)
- **활용 예**:
  - `The_Answer`: 단순 문자열("42")을 반환하는 함수를 툴로 만듦.
  - `Summarizer`: LangChain의 `LLMChain`을 툴로 래핑하여, 에이전트가 "요약" 기능을 도구처럼 필요할 때 꺼내 쓰도록 함.

## 3. 구조화된 정보 추출 (Extraction)

비정형 텍스트(자연어)에서 원하는 정보만 쏙쏙 뽑아내어 정형 데이터(JSON 등)로 변환합니다.

### `create_extraction_chain`

- **Schema**: 추출하고 싶은 데이터의 구조를 JSON Schema 형태로 정의합니다. (이름, 키, 머리색 등)
- **실행**: 텍스트를 입력하면, 정의된 스키마에 맞춰 정보를 추출해 JSON 형태로 반환합니다.
- **활용**: 뉴스 기사에서 인물 정보 추출, 상품 설명에서 스펙 추출 등에 유용합니다.

## 4. 평가 (Evaluation)

LLM이 생성한 응답의 품질을 자동으로 평가합니다.

### `load_evaluator("qa")`

- 질의응답(QA) 작업에 대한 평가를 수행합니다.
- **Input**: 질문
- **Prediction**: AI가 생성한 답변
- **Reference**: 모범 답안(정답)
- **결과**: `CORRECT` / `INCORRECT` 여부와 점수 등을 반환하여 모델의 성능을 측정할 수 있습니다.
