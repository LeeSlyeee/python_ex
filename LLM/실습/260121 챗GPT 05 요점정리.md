# 260121 챗GPT 05.py 핵심 요약

이 문서는 `260121 챗GPT 05.py` 실습을 통해 학습한 LangChain의 에이전트(Agent) 활용, 사용자 정의 도구(Custom Tool) 생성, 그리고 구조화된 데이터 추출 방법에 대한 요점 정리입니다. 특히 ReAct 에이전트와 OpenAI Functions/Tools 에이전트의 차이점, 그리고 Chain을 Tool로 변환하는 기법을 중점적으로 다룹니다.

## 1. ReAct 에이전트와 기본 도구 활용

### 1.1 ReAct 에이전트 (`create_react_agent`)

- **개념**: Reasoning(추론) + Acting(행동)의 결합. LLM이 스스로 계획을 세우고 도구를 사용한 뒤 관찰 결과를 바탕으로 다음 행동을 결정하는 방식입니다.
- **구성 요소**:
  - `llm`: 의사 결정을 내리는 두뇌 (예: GPT-4.1-mini)
  - `tools`: 사용 가능한 도구 목록 (예: Terminal)
  - `prompt`: `hub.pull("hwchase17/react")`에서 가져온 ReAct 전용 프롬프트
- **실습 내용**:
  - 터미널 도구(`terminal`)를 사용하여 특정 디렉터리(`sample_data`)의 파일 목록을 조회했습니다.
  - `allow_dangerous_tools=True` 설정을 통해 시스템 명령 실행 권한을 부여했습니다.

## 2. 사용자 정의 도구 (Custom Tools)

기본 제공 도구 외에 개발자가 직접 만든 함수나 로직을 에이전트가 사용할 수 있도록 확장할 수 있습니다.

### 2.1 단일 함수 래핑 (`Tool.from_function`)

- **개념**: 파이썬 함수를 `Tool` 객체로 감싸서 에이전트에게 제공합니다.
- **핵심 파라미터**:
  - `func`: 실제 실행될 함수
  - `name`: 도구의 고유 이름 (LLM이 선택하는 식별자)
  - `description`: **중요** LLM이 이 도구를 언제 사용해야 하는지 판단하는 기준이 되는 설명
- **예제**: `The_Answer` 도구를 만들어 "이 세계의 진리"라는 질문에 "42"라고 답하도록 구현.

### 2.2 체인(Chain)을 도구로 활용

- **개념**: 단순 함수뿐만 아니라, 또 다른 LLM 체인(예: 요약 체인)도 하나의 도구로 만들 수 있습니다.
- **활용**: 에이전트가 작업 수행 중 "텍스트 요약"이 필요하다고 판단하면 `Summarizer` 도구를 호출하여 처리합니다.
- **구조**: `LLMChain` 생성 -> `Tool.from_function(func=chain.run, ...)`으로 변환 -> 에이전트에 등록.

## 3. OpenAI 특화 에이전트 (Functions & Tools)

OpenAI 모델의 고유 기능인 Function Calling을 활용하여 더 정확하고 구조적으로 도구를 호출합니다.

### 3.1 OpenAI Functions Agent (`create_openai_functions_agent`)

- **특징**: ReAct의 텍스트 파싱 방식보다 더 안정적으로 함수 호출 인자를 JSON 형태로 생성합니다.
- **프롬프트**: `hub.pull("hwchase17/openai-functions-agent")`

### 3.2 OpenAI Tools Agent (`create_openai_tools_agent`)

- **특징**: OpenAI의 최신 **Tools API**를 사용하는 권장 방식입니다.
- **장점**: 병렬 함수 호출(Parallel Function Calling)을 지원하여 여러 도구를 동시에 실행할 수 있습니다.
- **실습**: `ddg-search`(DuckDuckGo) 도구를 사용하여 "서울과 부산의 날씨"를 검색했습니다. 이를 통해 외부 실시간 정보를 가져와 답변을 생성했습니다.

## 4. 구조화된 데이터 추출 (Structured Output Extraction)

비정형 텍스트(자연어)에서 원하는 정보만 쏙쏙 뽑아내어 정형 데이터(JSON)로 변환하는 기술입니다.

### 4.1 추출 체인 (`create_extraction_chain`)

- **Schema 정의**: 추출하고 싶은 데이터의 구조(이름, 키, 머리색 등)를 JSON Schema로 정의합니다.
- **동작**: 텍스트를 입력받아 스키마에 정의된 키(Key)와 타입(Type)에 맞춰 데이터를 추출합니다.
- **결과**: Python 리스트(List) 형태의 딕셔너리(Dictionary) 객체를 반환합니다.
- **참고**: 현재 `create_extraction_chain`은 Deprecated 상태이며, 향후 `ChatModel.with_structured_output` 사용이 권장됩니다.
