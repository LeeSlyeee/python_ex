# 260119 챗GPT 03.py 핵심 요약

이 문서는 `260119 챗GPT 03.py` 스크립트에서 다루는 LangChain의 핵심 기능과 실전 활용법을 정리한 요약본입니다. LangChain은 대규모 언어 모델(LLM)을 활용한 애플리케이션 개발을 돕는 강력한 프레임워크입니다.

## 1. LangChain 시작하기

### 주요 클래스 및 설정

- **`ChatOpenAI`**: OpenAI의 Chat Completion API(GPT-3.5, GPT-4 등)를 사용하기 위한 메인 클래스입니다.
  - `model_name`: 사용할 모델을 지정합니다. (예: `gpt-4.1-mini`)
  - `temperature`: 창의성을 조절합니다. 0에 가까울수록 결정적이고 사실적인 답변을, 1에 가까울수록 창의적인 답변을 생성합니다.

```python
chat = ChatOpenAI(model_name="gpt-4.1-mini", temperature=0)
result = chat.invoke("문자열 입력")
```

## 2. 메시지 시스템 (Messages)

LLM에게 단순한 문자열이 아닌, 역할이 부여된 메시지 객체를 전달하여 대화의 품질을 높입니다.

- **`SystemMessage`**: AI의 역할(Persona)이나 행동 지침을 설정합니다. (예: "당신은 요리 전문가입니다.")
- **`HumanMessage`**: 사용자의 질문이나 명령입니다.
- **`AIMessage`**: AI의 응답입니다. 이전 대화 기록을 주입하여(Few-shot) 문맥을 유지하는 데 사용됩니다.

```python
messages = [
    SystemMessage(content="You are a helpful assistant."),
    HumanMessage(content="안녕하세요!"),
    AIMessage(content="반갑습니다!"),
    HumanMessage(content="제 인사를 기억하나요?")
]
```

## 3. 프롬프트 템플릿 (Prompt Templates)

매번 프롬프트를 새로 작성하는 대신, 변수를 사용하여 재사용 가능한 템플릿을 만듭니다.

### 3.1. `PromptTemplate` (String Base)

- 일반적인 문자열 형태의 템플릿입니다.
- `{variable}` 형태로 변수 자리를 만들고, `format()` 메서드로 값을 채웁니다.

### 3.2. `ChatPromptTemplate` (Message Base)

- 채팅 모델에 특화된 템플릿으로, 메시지 목록(`System`, `Human`)으로 구성됩니다.
- 대화형 AI 개발 시 구조적인 프롬프트 관리에 유리합니다.

## 4. 정형화된 출력 (Structured Output)

LLM의 출력은 기본적으로 자유 형식의 텍스트입니다. 이를 시스템에서 사용하기 쉬운 Python 객체(리스트, 딕셔너리, 클래스 인스턴스)로 자동 변환합니다.

### `PydanticOutputParser`

- **Pydantic Model**: 원하는 데이터 구조를 클래스로 정의합니다.
- **Format Instructions**: 파서가 자동으로 생성해주는 "JSON 형식을 따르라"는 지시문을 프롬프트에 포함시킵니다.
- **Parse**: LLM의 텍스트 응답을 Python 객체로 파싱하여 반환합니다.

## 5. 체인 (Chains)

여러 컴포넌트(프롬프트, 모델, 파서 등)를 연결하여 하나의 파이프라인으로 만듭니다.

- **`LLMChain`**: 가장 기본적인 체인으로, 「프롬프트 + LLM (+ 파서)」를 묶어 입력값 하나로 전체 과정을 실행합니다.
- **`SimpleSequentialChain`**: 여러 개의 체인을 순차적으로 연결합니다. 앞선 체인의 출력이 다음 체인의 입력으로 자동 전달됩니다.
  - _활용 예_: [복잡한 문제 해결(Chain of Thought)] → [결과 요약]

## 6. 메모리 (Memory)

일회성 대화가 아닌, 연속적인 대화를 가능하게 합니다.

- **`ConversationBufferMemory`**: 대화의 모든 내용(User, AI 메시지)을 메모리에 저장합니다.
- **`ConversationChain`**: LLM과 Memory를 결합하여, 대화가 진행될 때마다 자동으로 이전 기록을 프롬프트에 포함시켜 맥락을 유지합니다.

---

> **Tip**: LangChain은 LLM 애플리케이션의 "뼈대" 역할을 합니다. 프롬프트 관리, 출력 파싱, 메모리 관리 등 반복적이고 복잡한 작업을 추상화하여 개발 생산성을 크게 높여줍니다.
