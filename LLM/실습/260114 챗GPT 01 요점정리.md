# 260114 챗GPT 01.py 핵심 요약

이 문서는 `260114 챗GPT 01.py` 스크립트에서 다루는 OpenAI API의 기초 사용법부터 고급 기능인 Function Calling까지의 핵심 내용을 정리한 요약본입니다.

## 1. 라이브러리 및 환경 설정

- **OpenAI SDK (`openai`)**: OpenAI 서버와 통신하며 텍스트 생성, 이미지 생성 등을 요청하기 위한 공식 라이브러리입니다.
- **Python-dotenv (`dotenv`)**: API 키와 같은 민감한 정보를 `.env` 파일에 저장하고 안전하게 로드하기 위해 사용합니다.
- **JSON 처리 (`json`)**: API의 응답 데이터와 Function Calling 시 전달되는 인자(Arguments)를 처리하기 위해 사용합니다.

## 2. 채팅 생성 기초 (Chat Completion)

### 기본 요청 구조

- **`client.chat.completions.create()`**: OpenAI 모델에게 대화 생성을 요청하는 핵심 메서드입니다.
- **입력 파라미터**:
  - `model`: 사용할 모델명 (예: `gpt-4o-mini`)
  - `messages`: 대화 내역을 담은 리스트입니다. 각 메시지는 `role`(역할)과 `content`(내용)를 속성으로 가집니다.

### 메시지 역할 (Roles)

- **`system`**: AI의 성격, 지침, 페르소나를 설정합니다.
- **`user`**: 질문을 하거나 명령을 내리는 실제 사용자입니다.
- **`assistant`**: AI의 답변입니다. 대화 맥락 유지를 위해 이전 답변을 이 역할로 다시 전달합니다.

## 3. 고급 기능 및 기술

### 대화 맥락 유지 (Memory Simulation)

- LLM 모델 자체는 이전 대화를 기억하지 않는 'Stateless' 형식이므로, 모델이 이전 내용을 기억하게 하려면 **전체 대화 이력(`messages` 리스트)**을 매 요청마다 다시 전달해야 합니다.

### 스트리밍 응답 (Streaming Response)

- **`stream=True`**: 응답이 완성될 때까지 기다리지 않고, 생성되는 즉시 한 조각(Chunk)씩 받아오는 기능입니다.
- 사용자 경험(UX) 측면에서 AI가 실시간으로 타이핑하는 듯한 효과를 줄 수 있습니다.
- 응답 객체를 `for` 루프로 순회하며 `chunk.choices[0].delta.content` 값을 출력하여 구현합니다.

### 함수 호출 (Function Calling / Tool Calling)

- AI 모델이 필요한 경우 외부 파이썬 함수를 실행하도록 '요청'하는 기능입니다.
- **흐름**:
  1.  **정의**: 사용 가능한 함수의 이름, 설명, 파라미터 명세(Schema)를 전달합니다.
  2.  **판단**: 모델은 대화 맥락상 함수 실행이 필요하다고 판단하면 `function_call` 정보를 담은 응답을 보냅니다.
  3.  **실행**: 코드가 해당 정보를 파싱하여 실제 파이썬 함수를 호출하고 결과값을 얻습니다.
  4.  **피드백**: 함수 실행 결과(`role: function`)를 다시 모델에게 전달하면, 모델이 이를 바탕으로 자연스러운 최종 답변을 생성합니다.

## 4. 모델 최적화 팁

- **`gpt-4o-mini` 활용**: 저렴한 비용과 빠른 속도로 간단한 텍스트 처리 및 함수 호출 작업에 매우 효율적입니다.
- **안전한 API 호출**: `response_message.function_call`이 존재하는지 먼저 확인하는 조건문을 활용하여 `NoneType` 에러를 방지해야 합니다.
- **데이터 정규화**: `model_dump_json()`을 활용하면 응답 객체의 전체 구조를 쉽게 파악하고 디버깅할 수 있습니다.
