# 딥러닝 자연어 처리 심화 코드 분석 보고서 (`260112 딥러닝자연어 02.py`)

이 문서는 **로이터 뉴스 카테고리 분류**와 **IMDB 영화 리뷰 감성 분석**을 위한 딥러닝 모델 구현 코드를 분석한 보고서입니다. **LSTM**, **CNN(Conv1D)**, **Self-Attention** 등 다양한 기법을 활용하여 자연어 처리 모델을 구축하고 성능을 비교합니다.

---

## 1. 전체 코드 흐름 (Overall Flow)

코드는 크게 세 가지 모델 구현부로 나뉩니다.

### [Part 1] 로이터 뉴스 카테고리 분류 (LSTM)

1.  **데이터 로드**: `reuters.load_data`를 통해 뉴스 기사 데이터셋을 불러옵니다. (빈도수 상위 1,000개 단어 사용)
2.  **데이터 탐색**: 뉴스 기사 수, 카테고리 수 등을 확인합니다.
3.  **전처리 (Preprocessing)**:
    - **패딩(Padding)**: 모든 기사의 길이를 100단어로 맞춥니다. (`pad_sequences`)
    - **원-핫 인코딩**: 46개의 뉴스 카테고리 레이블을 벡터화합니다. (`to_categorical`)
4.  **모델 설계**: `Embedding` -> `LSTM` -> `Dense(Softmax)` 구조로, 순차적인 텍스트 데이터를 LSTM으로 처리하여 다중 분류를 수행합니다.
5.  **학습 및 시각화**: `categorical_crossentropy` 손실 함수를 사용하여 학습하고, 학습/검증 손실 그래프를 출력합니다.

### [Part 2] IMDB 영화 리뷰 감성 분석 (CNN + LSTM)

1.  **데이터 로드**: `imdb.load_data`를 통해 영화 리뷰 데이터를 불러옵니다. (상위 5,000개 단어 사용)
2.  **전처리**: 리뷰 길이를 500단어로 패딩합니다.
3.  **모델 설계 (하이브리드 모델)**:
    - **Convolution Layer (Conv1D)**: 텍스트에서 지역적인 특징(패턴)을 추출합니다.
    - **MaxPooling1D**: 중요 특징만 남기고 차원을 축소합니다.
    - **LSTM**: 추출된 특징들의 흐름(순서)을 학습합니다.
    - **Dense(Sigmoid)**: 긍정/부정을 이진 분류합니다.
4.  **학습 및 시각화**: `binary_crossentropy` 손실 함수를 사용합니다.

### [Part 3] IMDB 영화 리뷰 감성 분석 (LSTM + Self-Attention)

1.  **데이터 로드 및 전처리**: Part 2와 동일하게 수행합니다.
2.  **모델 설계 (Attention 매커니즘)**:
    - **LSTM (return_sequences=True)**: 모든 시점(Time step)의 은닉 상태(Hidden state)를 다음 층으로 전달합니다.
    - **SeqSelfAttention**: 문맥(Context)을 고려하여 중요한 단어에 가중치를 더 부여하는 **Self-Attention** 기법을 적용합니다.
    - **Dense(Sigmoid)**: 최종적으로 긍정/부정을 분류합니다.
3.  **학습 및 시각화**: Attention 메커니즘이 적용된 모델의 성능을 확인합니다.

---

## 2. 주요 포인트 (Key Points)

### 🔑 LSTM (Long Short-Term Memory)

- 기존 RNN의 장기 의존성(Long-term Dependency) 문제를 해결한 모델입니다.
- 긴 문장의 뉴스나 리뷰 데이터에서 **앞부분의 문맥 정보를 끝까지 기억**하는 데 효과적이어서 높은 분류 성능을 보입니다.

### 🔑 Conv1D + LSTM 하이브리드 모델

- **Conv1D**: 이미지 처리의 CNN을 텍스트에 적용한 것으로, 문장 내에서 특정 단어 조합(n-gram)과 같은 **지역적 패턴**을 빠르게 찾아냅니다.
- **조합 효과**: Conv1D로 텍스트의 핵심 특징을 먼저 요약하고, 이를 LSTM에 입력으로 넣어 **학습 속도를 높이고 성능을 개선**하는 전략입니다.

### 🔑 Self-Attention (SeqSelfAttention)

- **"어디에 집중할 것인가?"**: 문장 내의 모든 단어가 서로 어떤 연관이 있는지를 계산하여, 예측 시 **중요한 단어에 더 큰 가중치**를 둡니다.
- LSTM이 순차적으로 정보를 처리하는 동안 놓칠 수 있는 **단어 간의 관계**를 보완하여, 모델이 문맥을 더 깊이 이해하게 돕습니다. `return_sequences=True` 설정이 필수적입니다.

### 🔑 과적합 방지 기법

- **Dropout**: 뉴런을 무작위로 비활성화하여 모델이 특정 데이터에 편향되지 않도록 합니다.
- **EarlyStopping**: 검증 손실(val_loss)이 더 이상 줄어들지 않으면 학습을 조기 종료하여 과적합을 막고 불필요한 연산을 줄입니다.
