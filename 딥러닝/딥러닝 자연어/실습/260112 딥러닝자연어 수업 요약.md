---

## 1. 자연어 처리 기초 (NLP Basics)

딥러닝 모델이 텍스트를 이해하려면 숫자(벡터)로 변환하는 과정이 필수적입니다.

### 📋 텍스트 전처리 (Preprocessing)

1.  **토큰화 (Tokenization)**
    - `Tokenizer` 객체를 사용하여 문장을 단어 단위로 쪼개고, 각 단어에 고유한 정수 인덱스(빈도수 순)를 부여합니다.
    - 컴퓨터가 이해할 수 있는 **정수 시퀀스**로 변환하는 첫 단계입니다.
2.  **패딩 (Padding)**
    - `pad_sequences`를 사용하여 문장들의 길이를 일정하게 맞춥니다.
    - 길이가 짧은 문장은 0을 채우고(Zero-padding), 긴 문장은 잘라내어 배열(Matrix) 형태의 입력을 만듭니다.
3.  **원-핫 인코딩 (One-Hot Encoding)** vs **워드 임베딩 (Word Embedding)**
    - **원-핫**: 단어 수만큼의 차원을 가지며, 하나만 1이고 나머지는 0인 희소 벡터(Sparse Vector). 단어 간 관계를 표현하지 못하고 메모리 낭비가 심함.
    - **임베딩**: 단어를 저차원의 실수 밀집 벡터(Dense Vector)로 매핑. 단어 간의 **의미적 유사성**을 학습할 수 있어 NLP에서 필수적으로 사용됨.

## 2. 심화 모델링 분석 (Advanced Modeling)

단순한 순환 신경망(RNN, LSTM)을 넘어 성능을 극대화하기 위한 복합 아키텍처와 최신 기법입니다.

### 🚀 [심화 1] CNN + LSTM 하이브리드 모델

이미지 처리에 강한 CNN과 시계열 처리에 강한 LSTM을 결합하여 장점을 취하는 구조입니다.

| 레이어 구조      | 역할 및 특징                                                                                                                                                                                       |
| :--------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Conv1D**       | - **지역적 특징 추출**: 텍스트의 'n-gram' 처럼, 단어 몇 개(커널 크기)를 묶어 지역적인 문맥이나 패턴을 감지합니다.<br>- 문장 전체를 훑으며 중요한 단어 조합(긍/부정 키워드 등)을 빠르게 찾아냅니다. |
| **MaxPooling1D** | - **정보 압축**: 추출된 특징 중 가장 중요한(큰) 값만 남겨 차원을 줄이고, 연산량을 감소시킵니다.                                                                                                    |
| **LSTM**         | - **시계열 학습**: CNN이 요약해준 특징들의 **순서와 흐름**을 학습하여 최종적으로 문맥을 파악합니다.                                                                                                |

> **💡 핵심 요약**: CNN은 **"무엇이 중요한지(What)"** 빠르게 찾아내고, LSTM은 **"어떤 문맥인지(How)"** 흐름을 읽습니다. 긴 텍스트에서 불필요한 정보를 걸러내고 핵심만 LSTM에 전달하므로 학습 속도와 성능이 모두 향상됩니다.

### ✨ [심화 2] LSTM + Self-Attention 모델

LSTM의 한계(긴 문장에서의 정보 손실)를 보완하고, 문맥 이해력을 대폭 향상시킨 최신 기법입니다.

#### 1. 구조적 특징

- **`LSTM(return_sequences=True)`**:
  - 일반적인 LSTM은 마지막 시점의 결과만 출력하지만, Attention을 쓰려면 **모든 시점(Time step)** 의 정보를 다 알아야 합니다.
  - 따라서 문장을 읽는 내내 생성되는 모든 은닉 상태(Hidden State)를 다음 층으로 전달합니다.
- **`SeqSelfAttention`**:
  - 모든 시점의 단어들이 서로 어떤 관계가 있는지 계산합니다.

#### 2. Self-Attention의 핵심 원리

- **"어디에 집중할 것인가?" (Attention Mechanism)**
  - 문맥상 예측(긍정/부정)에 결정적인 영향을 미치는 단어에 **높은 가중치(Attention Score)** 를 부여합니다.
  - 예) _"영화는 지루했지만 결말은 감동적이었다"_
    - 단순 LSTM은 '지루'라는 단어에 영향을 받아 부정으로 기울 수 있습니다.
    - Attention은 '결말', '감동적'이라는 단어와 문맥을 연결하여 긍정 쪽에 더 큰 가중치를 둡니다.

> **💡 핵심 요약**: LSTM이 문장을 순서대로 읽어나가는 독자라면, Self-Attention은 형광펜으로 **중요한 부분을 칠해가며 핵심 단어 간의 관계를 파악**하는 독해 전문가입니다. 이 둘을 결합하면 긴 리뷰에서도 문맥을 놓치지 않고 정확한 감성 분석이 가능합니다.

## 3. 부가적으로 알아야 할 것들

- **조기 종료 (Early Stopping)**
  - 학습 데이터에만 너무 익숙해지는 **과적합(Overfitting)** 을 방지하기 위해 필수적입니다.
  - 검증 데이터의 손실(`val_loss`)이 더 이상 줄어들지 않으면 학습을 스스로 멈춥니다.
- **드롭아웃 (Dropout)**
  - 신경망의 일부를 무작위로 끊어버려, 특정 뉴런에만 의존하는 현상을 막아 모델의 **범용성(Generalization)** 을 높입니다.
- **활성화 함수 (Activation Function)**
  - **`sigmoid`**: 이진 분류 (긍정/부정) -> 출력값 0 ~ 1.
  - **`softmax`**: 다중 분류 (뉴스 카테고리 46개) -> 출력값들의 합이 1 (확률 분포).
