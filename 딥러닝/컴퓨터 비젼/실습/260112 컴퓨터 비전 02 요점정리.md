# 260112 컴퓨터 비전 02.py 핵심 요약

이 문서는 `260112 컴퓨터 비전 02.py` 스크립트의 주요 기능과 사용된 TensorFlow/Keras 기반의 딥러닝 모델 구현 내용을 정리한 요약본입니다.

## 1. 라이브러리 및 데이터셋

- **TensorFlow & Keras**: 딥러닝 모델 구축 및 학습을 위한 핵심 프레임워크입니다.
- **NumPy**: 데이터 처리 및 변환을 위해 사용됩니다.
- **Matplotlib**: 데이터 시각화 및 학습 결과 그래프 출력을 위해 사용됩니다.
- **데이터셋 (`ds.mnist`, `ds.cifar10`)**: 손글씨 숫자(MNIST) 및 사물 이미지(CIFAR-10) 데이터셋을 로드하여 학습에 사용합니다.

## 2. 데이터 전처리 및 시각화

### 데이터 로드 및 확인

- **`load_data()`**: 학습용(`train`) 및 테스트용(`test`) 데이터를 불러옵니다.
- **`shape` 확인**: 데이터의 차원(개수, 너비, 높이 등)을 출력하여 구조를 파악합니다.

### 데이터 시각화

- **`plt.imshow()`**: 이미지 데이터를 시각적으로 확인합니다. `cmap='gray'` 옵션으로 흑백 이미지를 출력할 수 있습니다.
- **`plt.subplot()`**: 여러 이미지를 하나의 윈도우에 격자 형태로 배치하여 비교합니다.

### 데이터 변환 (Preprocessing)

- **`reshape()`**: 2차원 이미지(28x28)를 1차원 벡터(784)로 변환하여 MLP 입력에 맞게 구조를 변경합니다.
- **정규화 (Normalization)**: 픽셀 값을 0~255 범위에서 0.0~1.0 범위로 변환(`astype(np.float32)/255.0`)하여 학습 안정성을 높입니다.
- **원-핫 인코딩 (One-Hot Encoding)**: `to_categorical` 함수를 사용하여 레이블(정답)을 확률 벡터 형태로 변환합니다.

## 3. 다층 퍼셉트론 (MLP) 모델 구축

### 모델 구조 정의 (`Sequential`)

- **`Dense` 레이어**: 완전 연결 계층(Fully Connected Layer)을 구성합니다.
  - **`units`**: 뉴런(노드)의 개수를 설정합니다.
  - **`activation`**: 활성화 함수를 지정합니다. (`tanh`, `relu`, `softmax` 등)
  - **`input_shape`**: 입력 데이터의 형태를 정의합니다 (첫 번째 레이어에 필수).

### 모델 컴파일 (`compile`)

- **`optimizer`**: 최적화 알고리즘을 선택합니다. (`SGD`, `Adam` 등)
- **`loss`**: 손실 함수를 지정합니다. (`MSE`, `categorical_crossentropy` 등)
- **`metrics`**: 평가 지표를 설정합니다. (`accuracy` 등)

## 4. 학습 및 평가

### 모델 학습 (`fit`)

- **`epochs`**: 전체 데이터셋에 대한 반복 학습 횟수를 지정합니다.
- **`batch_size`**: 한 번의 업데이트에 사용할 데이터 샘플 크기를 지정합니다.
- **`validation_data`**: 학습 도중 검증 데이터셋을 사용하여 성능을 모니터링합니다.
- **`verbose`**: 학습 진행 상황 출력 방식을 설정합니다.

### 모델 평가 (`evaluate`)

- 테스트 데이터셋을 사용하여 최종 성능(정확률 등)을 측정합니다.

## 5. 최적화 기법 비교 (SGD vs Adam)

- 동일한 구조의 MLP 모델에 대해 **SGD(Stochastic Gradient Descent)**와 **Adam(Adaptive Moment Estimation)** 옵티마이저를 각각 적용하여 학습 성능을 비교합니다.
- 학습 결과(`history`)를 그래프로 시각화하여 수렴 속도와 정확도 차이를 분석합니다.

## 6. 심층 신경망 (Deep MLP) 및 모델 저장

### 심층 신경망 (DMLP)

- 은닉층(Hidden Layer)을 여러 개 쌓아 모델의 표현력을 높입니다. (`1024 -> 512 -> 512 -> 10`)
- **ReLU** 활성화 함수를 사용하여 깊은 신경망에서의 기울기 소실 문제를 완화합니다.

### 모델 저장 (`save`)

- 학습 완료된 모델을 HDF5 포맷(`.h5`) 파일로 저장하여 추후 재사용할 수 있도록 합니다.
- `os.path.join`을 사용하여 경로 호환성을 확보합니다.

### 학습 결과 시각화

- `matplotlib`를 사용하여 에포크(epoch)에 따른 정확도(Accuracy)와 손실(Loss) 변화 추이를 그래프로 출력합니다.
