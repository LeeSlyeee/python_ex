# 260109 컴퓨터 비전 01.py 핵심 요약

이 문서는 `260109 컴퓨터 비전 01.py` 스크립트의 주요 기능과 사용된 OpenCV 핵심 기술들을 정리한 요약본입니다.

## 1. 라이브러리 및 기본 설정

- **OpenCV (`cv2`)**: 컴퓨터 비전 및 이미지 처리를 위한 핵심 라이브러리입니다.
- **NumPy (`numpy`)**: 이미지 데이터를 배열 형태로 효율적으로 처리하기 위해 사용합니다.
- **경로 설정 (`os`)**: `os.path.dirname(__file__)` 등을 사용하여 코드의 이식성을 높이고 파일 경로 문제를 방지합니다.

## 2. 이미지 처리 기초

### 이미지 로드 및 표시

- **`cv.imread(path)`**: 이미지 파일을 로드하여 NumPy 배열로 반환합니다.
- **`cv.imshow(winname, mat)`**: 윈도우 창에 이미지를 출력합니다.
- **`cv.waitKey(delay)`**: 키보드 입력을 대기합니다. `0`이면 무한 대기, 양수면 해당 ms초 만큼 대기합니다.
- **`cv.destroyAllWindows()`**: 생성된 모든 OpenCV 윈도우를 닫습니다.

### 이미지 변환 및 저장

- **색상 공간 변환**: `cv.cvtColor(src, code)`를 사용해 BGR 이미지를 Grayscale 등으로 변환합니다. (예: `cv.COLOR_BGR2GRAY`)
- **크기 조절 (Resizing)**: `cv.resize(src, dsize, fx, fy)` 함수로 이미지 크기를 변경합니다. `dsize`로 절대 크기를, `fx`, `fy`로 비율을 지정할 수 있습니다.
- **이미지 저장**: `cv.imwrite(filename, img)` 함수를 사용하여 변환된 이미지를 파일로 저장합니다.

## 3. 동영상 및 웹캠 처리

### 웹캠 영상 출력

- **`cv.VideoCapture(index)`**: 웹캠 장치(카메라)에 연결합니다. `0`은 기본 장치를 의미합니다.
- **`cap.read()`**: 카메라로부터 프레임 한 장을 읽어옵니다. (반환값: 성공여부 `ret`, 프레임 이미지 `frame`)
- **`cap.release()`**: 카메라 장치 자원을 해제합니다.

### 영상 프레임 캡처 및 병합

- 루프 내에서 특정 키(예: 'c') 입력을 감지하여 현재 `frame`을 리스트에 저장합니다.
- **`np.hstack((img1, img2))`**: 수집된 여러 프레임 이미지를 가로(수평) 방향으로 이어 붙여 하나의 이미지로 병합합니다.

## 4. 그리기 기능 (Drawing)

- **`cv.rectangle(img, pt1, pt2, color, thickness)`**: 이미지 위에 직사각형을 그립니다.
- **`cv.putText(img, text, org, font, scale, color, thickness)`**: 이미지 위에 텍스트를 작성합니다.
- **`cv.circle(img, center, radius, color, thickness)`**: 이미지 위에 원을 그립니다. `thickness=-1`일 경우 내부가 채워진 원(점)이 됩니다.

## 5. 이벤트 처리 (Event Handling)

### 마우스 콜백 (Mouse Callback)

- **`cv.setMouseCallback(winname, onMouse)`**: 특정 윈도우에서 마우스 이벤트가 발생했을 때 실행할 콜백 함수를 등록합니다.

### 주요 마우스 이벤트 패턴

1.  **클릭 처리**: `cv.EVENT_LBUTTONDOWN` (좌클릭), `cv.EVENT_RBUTTONDOWN` (우클릭) 등의 이벤트를 감지하여 도형을 그립니다.
2.  **드래그 (Drag)**: `LBUTTONDOWN` 시 시작 좌표를 저장하고, `LBUTTONUP` 시 종료 좌표를 받아 두 지점을 잇는 도형을 그립니다. `global` 변수를 활용해 상태(시작 좌표)를 유지합니다.
3.  **페인팅 (Painting)**: `cv.EVENT_MOUSEMOVE` 이벤트와 `flags` (예: `cv.EVENT_FLAG_LBUTTON`)를 조합하여, "마우스를 누른 채 이동"하는 동작을 감지, 연속적으로 원을 그려 붓으로 그리는 듯한 효과를 냅니다.
