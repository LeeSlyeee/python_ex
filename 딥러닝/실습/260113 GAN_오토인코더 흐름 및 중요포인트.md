# GAN & 오토인코더 코드 분석 보고서 (`260113 GAN_오토인코더.py`)

이 문서는 MNIST 데이터셋을 사용하여 **GAN(Generative Adversarial Network)**과 **오토인코더(Autoencoder)**를 구현한 코드의 흐름과 핵심 내용을 정리한 것입니다.

---

## 1. GAN (생성적 적대 신경망) 흐름

### [Step 1] 라이브러리 임포트 및 모델 설계

- **생성자(Generator)**: 랜덤 노이즈(100차원)를 입력받아 실제와 유사한 이미지(28x28)를 생성합니다.
  - 주요 레이어: `Dense` -> `Reshape` -> `UpSampling2D` (크기 확대) -> `Conv2D`
  - 활성화 함수: `LeakyReLU`(중간층), `tanh`(출력층)
- **판별자(Discriminator)**: 이미지를 입력받아 진짜(1)인지 가짜(0)인지 판별하는 이진 분류기입니다.
  - 주요 레이어: `Conv2D` (stride=2로 다운샘플링) -> `LeakyReLU` -> `Dropout` -> `Dense`
  - 활성화 함수: `sigmoid`(출력층, 0~1 확률)
- **GAN 모델**: 생성자와 판별자를 연결합니다. 학습 시 판별자는 고정(`trainable=False`)되고 생성자만 학습됩니다.

### [Step 2] GAN 학습 과정 (`gan_train` 함수)

1.  **데이터 준비**: MNIST 데이터를 불러와 -1 ~ 1 사이 값으로 정규화합니다.
2.  **판별자 학습 (Discriminator Training)**:
    - 실제 이미지(Real)와 생성된 가짜 이미지(Fake)를 각각 입력하여 판별자를 학습시킵니다.
    - 목표: 실제는 1, 가짜는 0으로 분류하도록 학습.
3.  **생성자 학습 (Generator Training)**:
    - GAN 모델을 통해 생성자를 학습시킵니다.
    - 목표: 생성한 이미지가 판별자에게 1(진짜)로 분류되도록 학습 (판별자를 속임).
4.  **시각화**: 일정 에포크마다 생성된 이미지를 파일로 저장하여 학습 경과를 확인합니다.

---

## 2. 오토인코더 (Autoencoder) 흐름

### [Step 1] 데이터 전처리 및 모델 설계

- **전처리**: MNIST 데이터를 불러와 0 ~ 1 사이 값으로 정규화하고 차원을 (28, 28, 1)로 변경합니다.
- **인코더 (Encoder)**: 입력 이미지를 압축하여 잠재 공간(Latent Space)의 특징을 추출합니다.
  - 구조: `Conv2D` -> `MaxPooling2D` (차원 축소) -> `Conv2D` ...
- **디코더 (Decoder)**: 압축된 특징을 다시 원래 이미지 크기로 복원합니다.
  - 구조: `Conv2D` -> `UpSampling2D` (차원 확대) -> ... -> `Conv2D` (복원)

### [Step 2] 학습 및 결과 확인

- **학습**: 입력(`X_train`)과 정답(`X_train`)을 동일하게 설정하여, 입력 이미지를 그대로 복원하도록 학습합니다. (비지도 학습)
- **손실 함수**: 픽셀 단위의 이진 분류 문제로 간주하여 `binary_crossentropy`를 사용하거나, `mse`를 사용할 수도 있습니다.
- **시각화**: 테스트 데이터의 원본 이미지와 오토인코더가 복원한 이미지를 비교하여 출력합니다.

---

## 3. 주요 포인트 (Key Points)

### 🔑 GAN의 핵심 원리

- **경쟁적 학습**: 생성자는 판별자를 속이려 하고, 판별자는 속지 않으려 노력하는 과정에서 두 모델의 성능이 동시에 향상됩니다.
- **LeakyReLU**: GAN에서는 `ReLU`보다 `LeakyReLU`를 주로 사용하여, 뉴런이 죽는(Dying ReLU) 현상을 방지하고 학습 안정성을 높입니다.
- **Tanh 활성화**: 생성자의 출력층에 `tanh`를 사용하여 픽셀 값을 -1 ~ 1 범위로 생성합니다. 이는 학습 안정성에 도움을 줍니다.

### 🔑 차원 조절 (UpSampling vs Pooling/Stride)

- **MaxPooling / Stride**: 이미지의 크기를 줄여 특징을 압축하고 연산량을 줄입니다. (판별자, 인코더에서 사용)
- **UpSampling2D**: 이미지의 크기를 물리적으로 키워(예: 7x7 -> 14x14) 고해상도 이미지를 생성하거나 데이터를 복원합니다. (생성자, 디코더에서 사용)

### 🔑 오토인코더의 목적

- **데이터 압축 및 복원**: 입력 데이터의 핵심 특징만 학습하여 효율적으로 데이터를 표현합니다.
- **노이즈 제거 (Denoising)**: 학습 시 입력에 노이즈를 섞고 원본을 정답으로 주면, 노이즈를 제거하는 모델을 만들 수 있습니다.
