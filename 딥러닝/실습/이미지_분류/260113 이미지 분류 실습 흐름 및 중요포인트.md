# 이미지 분류 (말 vs 사람) 코드 분석 보고서 (`260113 이미지 분류 실습.py`)

이 문서는 **CNN(Convolutional Neural Network)**을 사용하여 말(Horse)과 사람(Human)을 구분하는 이진 분류(Binary Classification) 딥러닝 코드의 전체적인 흐름과 핵심 포인트를 정리한 것입니다.

---

## 1. 전체 코드 흐름 (Overall Flow)

### [Step 1] 라이브러리 및 데이터 경로 설정

- `tensorflow`, `cv2`, `matplotlib` 등 필요한 라이브러리를 임포트합니다.
- `os.path`를 사용하여 스크립트 실행 위치를 기준으로 데이터셋 경로(`dataset/horse-or-human`)를 동적으로 설정합니다.

### [Step 2] 데이터 탐색 및 시각화

- `os.listdir`로 파일 목록을 확인하고, 각 클래스(말, 사람)별 데이터 개수를 출력합니다.
- `matplotlib`를 사용하여 학습 데이터 중 일부(말 5장, 사람 5장)를 시각화하여 데이터의 형태를 확인합니다.

### [Step 3] CNN 모델 설계 (Deep Architecture)

- **Conv2D + MaxPool2D** 조합을 5번 반복하여 이미지의 특징을 깊이 있게 추출합니다.
  - 초기 레이어는 저수준 특징(선, 면 등)을, 후반 레이어는 고수준 특징(눈, 귀, 얼굴 형태 등)을 학습합니다.
- **Flatten**: 3차원 특징 맵을 1차원 벡터로 변환합니다.
- **Dense (Output)**: **이진 분류**이므로 출력 노드는 **1개**, 활성화 함수는 **`sigmoid`**를 사용합니다.

### [Step 4] 모델 컴파일 및 전처리

- **Loss Function**: 두 개의 클래스를 구분하므로 `binary_crossentropy`를 사용합니다.
- **Optimizer**: `Adam` (Learning Rate 0.001)을 사용합니다.
- **Preprocess**: `ImageDataGenerator`를 사용하여 픽셀 값을 0~1로 정규화(`rescale=1/255`)합니다.
- **Generator**: `flow_from_directory`를 통해 폴더 구조로부터 이미지 데이터를 자동으로 불러오고, `(300, 300)` 크기로 리사이징합니다.

### [Step 5] 학습 및 결과 확인

- `model.fit`으로 학습을 진행하며, `steps_per_epoch`를 설정하여 배치 단위로 학습합니다.
- 학습 종료 후 Accuracy와 Loss 그래프를 그려 학습 경과를 시각적으로 확인합니다.

### [Step 6] 사용자 데이터 예측 (Prediction)

- 테스트 폴더(`test`)에 있는 이미지를 `OpenCV`로 불러옵니다.
- 학습 때와 동일하게 **리사이징(300x300)** 및 **정규화(/255.0)** 전처리를 수행합니다.
- `model.predict`로 예측 확률을 계산하고, 0.5를 기준으로 True/False(클래스 분류)를 판별합니다.

---

## 2. 주요 포인트 (Key Points)

### 🔑 이진 분류 (Binary Classification) 설정

- **출력층 구성**: 다중 분류(Softmax, 노드 N개)와 달리, 이진 분류는 **노드 1개**와 **`sigmoid`** 활성화 함수를 사용합니다. 결과값은 0~1 사이의 확률이 되며, 일반적으로 0.5보다 작으면 0번 클래스, 크면 1번 클래스로 판단합니다.
- **손실 함수**: `binary_crossentropy`를 사용하여 확률 분포 간의 차이를 계산합니다.

### 🔑 깊은 합성곱 신경망 (Deep CNN)

- 이 모델은 5개의 `Conv2D` 레이어를 쌓은 비교적 깊은 구조입니다.
- 이미지 크기가 `300x300`으로 비교적 크기 때문에, 여러 번의 풀링(Pooling)을 거쳐 특징 맵의 크기를 줄이면서 추상화된 특징을 효율적으로 추출하도록 설계되었습니다.

### 🔑 이미지 데이터 제너레이터 (ImageDataGenerator)

- 메모리 효율성을 위해 모든 이미지를 한 번에 로드하지 않고, `flow_from_directory`를 사용해 **배치 단위(Batch Size)**로 필요한 만큼만 메모리에 올려 학습합니다.
- 디렉토리 이름(horses, humans)을 기반으로 자동으로 라벨링(0, 1)을 수행하므로 별도의 라벨링 작업이 필요 없습니다.

### 🔑 OpenCV와 차원 변환 주의점

- 예측 과정에서 `cv2.imread`로 읽은 이미지는 `(Height, Width, Channel)` 형태입니다.
- 모델은 `(Batch Size, Height, Width, Channel)` 형태의 4차원 입력을 기대하므로, 여러 이미지를 리스트로 묶어 `np.array`로 변환함으로써 차원을 맞춰줘야 합니다. (`img = np.array(img)` 수행 시 자동으로 배차 차원 생성됨)
